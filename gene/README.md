# Gene reference data

COSMIC **Cancer Gene Census** (v103, GRCh38) for this project.

| File | Description |
|------|-------------|
| `Cosmic_CancerGeneCensus_v103_GRCh38.tsv` | Official-style census export |
| `oncogens.tsv` | Same genes + Ensembl IDs and formatted coordinates (preferred for scripts) |

Key field for interpretation: **`ROLE_IN_CANCER`** (`oncogene`, `TSG`, `fusion`, or combined).

Full project overview, pipeline, and citations: **[`../README.md`](../README.md)**
