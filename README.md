# Pilot — G-quadruplex (G4) impact of ClinVar SNVs in cancer genes

Analysis pipeline asking whether **germline ClinVar SNPs in G-rich sequence** change predicted **G-quadruplex (QGRS) stability** (G-score) in regulatory UTRs and upstream regions of **COSMIC Cancer Gene Census** genes.

Genome build: **GRCh38** · Annotation: **GENCODE v46** · G4 caller: **[qgrs-cpp](qgrs-cpp/)**

---

## Workflow (high level)

```
COSMIC gene list + GENCODE/ClinVar
        ↓
Extract reference regions (TSS upstream 500 bp, 5′UTR, 3′UTR)
        ↓
Find G-related ClinVar SNPs overlapping QGRS motifs (reference)
        ↓
Build mutant FASTA → run QGRS on wild-type vs mutant
        ↓
Compare G-scores / motif changes → tables & poster figures
```

| Step | Scripts (in `scripts/`) | Main outputs |
|------|-------------------------|--------------|
| 1. Gene & regions | `select_transcripts_and_extract_regions.py` | `data/regions/`, `data/fasta/*.reference.fa` |
| 2. Reference QGRS | `run_qgrs_on_multifasta.py` | `initial_fasta/results_*` |
| 3. SNP discovery | `find_tss_qgrs_clinvar_snps.py`, `find_spliced_qgrs_clinvar_snps.py` | `initial_snp/*_snp/` |
| 4. Mutant sequences | `create_mutant_fasta_from_g_related_snps.py` | `mutant_fasta/` |
| 5. Mutant QGRS | `run_qgrs_on_multifasta.py` | `mutant_qgrs/` |
| 6. Wild vs mutant | `compare_qgrs_wild_vs_mutant.py` | `compare_mutant_wild/` |
| 7. Figures & reports | `make_compare_figures.py`, `make_final_poster_*.py`, etc. | `results_*` |

**Note:** Some scripts still hard-code `PROJECT_ROOT` as `/Users/ritika/Desktop/pilot`. Update that path (or switch to repo-relative paths) before running on another machine.

## Requirements

- **Python 3** with `matplotlib`, `pandas` (and standard library)
- **qgrs-cpp** built: `cd qgrs-cpp && make` → binary at `qgrs-cpp/bin/qgrs`
- Large reference files under `data/` (not always shipped with the repo)

Example — run QGRS on a FASTA:

```bash
python scripts/run_qgrs_on_multifasta.py \
  --fasta data/fasta/5utr.reference.fa \
  --outdir initial_fasta/results_5utr
```

Example — compare wild vs mutant after both QGRS runs:

```bash
python scripts/compare_qgrs_wild_vs_mutant.py \
  --region 5utr \
  --wild-summary initial_fasta/results_5utr/5utr_reference.qgrs_summary.tsv \
  --mutant-summary mutant_qgrs/5utr/5utr_mutant.qgrs_summary.tsv \
  --outdir compare_mutant_wild/5utr
```

Poster figures are generated by the `make_final_poster_*.py` scripts (run from repo root after comparison tables exist).
